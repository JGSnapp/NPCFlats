# NPCFlats

NPCFlats представляет из себя Telegram mini app, в котором реализована игра в тематике обустройства квартир. Человек должен собтирать персонажей и, учитывая их особенности, искать и покупать для них такую мебель, чтобы они приносили как можно больше денег. В игре реализованы покупка и продажа мебели, квартир, внутренний магазин и аукцион, "кейсы со случайными предметами" и другие механики.
